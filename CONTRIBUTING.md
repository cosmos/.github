# Contributing

This document sets the contribution baseline for every repository in the Cosmos
organization. Individual repositories add their own build and test instructions
on top of it.

## Conduct

The [Code of Conduct](https://github.com/cosmos/.github/blob/main/CODE_OF_CONDUCT.md)
applies throughout this organization. Report concerns to
[conduct@cosmos.network](mailto:conduct@cosmos.network).

## Security

Never open a public issue, pull request, or discussion for a suspected
vulnerability. Report it through the
[security policy](https://github.com/cosmos/security/blob/main/SECURITY.md)
instead.

## Pull requests

- Limit each pull request to one logical change, and split larger work.
- State what changed and why, and link the issue it closes.
- Cover both the expected path and the error path with tests.
- Confirm that CI passes before you request review.
- Keep your branch current with the base branch.

## Review

We propose and review every change in public on GitHub. Maintainers may close a
pull request that falls outside the project's scope, that its author has
abandoned, or that its author has not read.

## AI assistance

You may use AI tooling provided you take responsibility for what it produces.
Read the output, and be ready to explain it. Do not open a pull request
containing work you have not read yourself. Maintainers treat repeated
low-effort submissions as a conduct matter.
